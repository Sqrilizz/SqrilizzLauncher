# StatusServer

Сервис мониторинга и пинга Minecraft-серверов в реальном времени на Elixir.

## Запуск

```bash
mix deps.get
mix run --no-halt
```

Порт по умолчанию: `4040` (можно задать через переменную окружения `PORT=4040`).

## API

- `GET /health` — проверка работоспособности сервиса.
- `GET /api/servers` — список отслеживаемых серверов со статусом (онлайн, игроки, MOTD, пинг, фавикон).
- `POST /api/servers` — добавить сервер в мониторинг (JSON: `{"id": "my_srv", "name": "Survival", "host": "127.0.0.1", "port": 25565}`).
- `DELETE /api/servers/:id` — удалить сервер из мониторинга.
- `GET /api/ping?host=...&port=25565` — мгновенный опрос любого сервера.
- `GET /ws` — WebSocket подключение для получения обновлений статусов серверов в реальном времени.
