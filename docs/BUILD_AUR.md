# Arch Linux and AUR

The repository contains a binary AUR package in `packaging/aur/sqrilizz-launcher-bin`.
It downloads the matching GitHub release AppImage and installs a desktop entry and launcher command.

## Local package

Update `pkgver` in `packaging/aur/sqrilizz-launcher-bin/PKGBUILD` to the release version, then run:

```bash
cd packaging/aur/sqrilizz-launcher-bin
makepkg -si
```

## AUR installation

After publishing the package to the AUR, users can install it with:

```bash
yay -S sqrilizz-launcher-bin
```

The package expects an AppImage with the release name generated by Tauri:

```text
Sqrilizz Launcher_<version>_amd64.AppImage
```
