# Extra Commands

On Unix systems, you are able to add additional commands to the command line to improve your experience. Simply call `source <sqrilizz_data_dir>/internal/commands.sh`, replacing `<sqrilizz_data_dir>` with the path to your data directory.

## Commands

- `sqrilizz-instance-cd <instance> and sqrilizz-inst-cd <instance>`: Easily change the working directory to the given instance
