### ✨ Новая система новостей

**Заменили новости от Modrinth на собственную систему!**

- ✅ **Полный контроль**: Теперь новости загружаются с `https://www.sqrilizz.fun/api/launchernews`
- ✅ **API работает**: Сервер уже развернут и работает!
- ✅ **Приватность**: Сервер НЕ логирует IP адреса пользователей
- ✅ **Надежность**: Автоматический fallback на локальный файл если API недоступен
- ✅ **Простота**: Легко добавлять новости через API или редактируя файл
- ✅ **Безопасность**: POST/DELETE защищены API ключом `SecretSqrilizzAPI`
- ✅ **Кеширование**: 5 минут для снижения нагрузки на сервер
- ✅ **Плейсхолдер**: Красивое сообщение если новостей нет

**Как добавить новость:**

```bash
curl -X POST https://www.sqrilizz.fun/api/launchernews \
  -H "Content-Type: application/json" \
  -H "X-API-Key: SecretSqrilizzAPI" \
  -d '{"title":"Заголовок","summary":"Текст","link":"https://..."}'
```

**Файлы**:

- `apps/app-frontend/src/App.vue` - логика загрузки новостей
- `news-api-server/` - Node.js API сервер (уже развернут!)
- `NEWS_GUIDE.md` - руководство по использованию
- `ADD_NEWS_QUICK.md` - быстрый гайд как добавить новость
- `news-api-server/README.md` - полная инструкция по деплою

**Кнопка "View all news"** теперь ведет на GitHub Releases вместо Modrinth.

## Как протестировать изменения

### Запуск в dev режиме:

```bash
pnpm app:dev
```

### Сборка для продакшена:

```bash
pnpm app:build
```

### Проверить что исправлено:

1. **Закрытие лаунчера**: Закройте окно - лаунчер должен полностью завершиться
2. **Fast Reconnect**: Запустите инстанс, закройте его, вернитесь на главную - должна появиться кнопка "Fast Reconnect"
3. **Меню модов**: Откройте любой инстанс → вкладка Content → проверьте что меню выглядит компактно и современно
4. **Фильтры**: Попробуйте фильтры модов - они должны быть с закругленными углами и плавными переходами
5. **Hover эффекты**: Наведите на элементы списка модов - должна быть плавная анимация
