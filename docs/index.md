# Sqrilizz Documentation

This is the user and developer documentation for Sqrilizz.

To get started with the launcher, check out the [user guide](getting_started.md).

Documentation for the CLI can be found by running `sqrilizz help`. Examples for the library can be found in the code for the CLI, as it is a simple implementation of all the functionality. All library crates should have code documentation hosted on [docs.rs](https://docs.rs).
