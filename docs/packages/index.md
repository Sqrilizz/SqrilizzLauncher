# Packages

Packages are a blanket term for content you can add to an instance, such as mods, resource packs, and datapacks.

## Repositories

Repositories are sources for packages. Built-in repositories include:
- Modrinth
- Smithed
- CurseForge

All of these repositories are natively supported out of the box in Sqrilizz.

## Installing a package

>>> Browse for packages

First, you have to find some packages to install.

+++ App
Navigate to the packages tab at the top to start browsing. 

![](../assets/screenshots/gui_packages.png)
+++ CLI
Run `sqrilizz package browse` to enter the package browser. Keybinds are written in brackets next to items, and at the bottom. Press `q` to exit.
+++

>>> Find the package

Search for the package you want using the search bar, and select it to view more info.

>>> Install the package

+++ App
Click the `Install` button to add the package to the selected instance.
+++ CLI
Press `i` on the package to install it to your selected instance.
+++
