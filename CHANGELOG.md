# Changelog

All notable changes to Sqrilizz Launcher are documented in this file.

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-01-08

### Added

- Initial release
- Mod and modpack management
- Multiple instance support
- Modrinth integration
- News feed with API
- Auto-update functionality
- Custom instance icons
- Compact mod list interface (22px height)
- Linux compatibility warning
- Instance groups
- Automatic caching
- File association for .mrpack files

### Platform Support

- Windows 10/11 (x64)
- Linux (Ubuntu 20.04+, Debian, Fedora,)

### Known Issues

- Linux: File picker dialogs may crash due to WebKit limitations. Use drag & drop instead.

### Technical

- Tauri 2.8.5
- Vue 3 + TypeScript
- Rust backend
- Tailwind CSS

- Inspired by [Modrinth Launcher](https://modrinth.com/app)
